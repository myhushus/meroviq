# Meroviq Website

Static company website for GitHub Pages.

## Files

- `index.html`
- `assets/css/styles.css`
- `assets/js/main.js`
- `privacy/index.html`
- `terms/index.html`
- `CNAME`

## Publish with GitHub Pages

1. Upload all files to the repository root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select `main` and `/(root)`.
5. Save.
6. Set the custom domain to `meroviq.com`.

## Before publishing

- Confirm `remero@meroviq.com` is active.
- Review the Privacy Policy and Terms of Use.
- Update product descriptions and statuses when needed.
